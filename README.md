# K-Fitness

2023년 웹 프로그래밍 프로젝트로 제작한 헬스장 관리·운동 정보 웹 애플리케이션입니다.

> 현재 서비스 운영은 종료되었습니다. 학습 과정과 최종 결과물을 기록하기 위한 포트폴리오 저장소입니다.

## 주요 기능

- 회원가입·로그인
- 운동 정보와 지도
- 문의·공지 게시판
- 마이페이지, 결제·라커 화면

## 기술

- Node.js, Express, EJS
- MySQL
- HTML, CSS, JavaScript

## 실행

1. `npm install`
2. `.env.example`을 `.env`로 복사하고 값을 설정합니다.
3. `node app.js`
4. 브라우저에서 `http://localhost:3000`을 엽니다.

실제 환경 변수와 `node_modules`는 저장소에 포함하지 않습니다.
